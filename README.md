Jornada Milhas - Playwright

Projeto desenvolvido durante meus estudos de automação de testes com Playwright, utilizando como base o projeto Jornada Milhas da Alura.

🧪 Tecnologias
Playwright
TypeScript
Node.js
Faker


📌 O que foi praticado

Foram criados testes automatizados para alguns dos principais fluxos da aplicação:

Cadastro de usuário
Login
Edição de perfil
Busca de passagens
Validações de páginas e mensagens
Geração de dados com Faker
Page Object Model (POM)
Fixtures
Autenticação e reutilização de sessão
Mock de API


▶️ Como executar

Primeiro, é necessário iniciar a API do projeto.

Depois, iniciar o front-end:

npm install
npm start

O front-end será executado em:

http://localhost:4200

Depois, execute os testes:

npx playwright test

Para executar os testes com a interface do Playwright:

npx playwright test --ui


🎯 Objetivo

Projeto criado para praticar os conceitos de automação de testes E2E com Playwright e fazer parte do meu portfólio de estudos em QA.
